# PuppiLOVE — proyecto de portfolio
Simulador cozy de mascotas en JavaScript, Canvas 2D y Vite. Explora persistencia local, renderizado isométrico, gestión de inventario y progresión. El módulo data.js separa catálogo, regiones y persistencia del motor heredado. Proyecto en desarrollo: presentar como prototipo, no como juego comercial terminado.

## 4.5 — Pulido audiovisual
Paletas por isla, partículas, respiración de mascotas, siluetas SVG diferenciadas, música sintetizada por región, ambiente climático y cuatro niveles gráficos manuales. Ajustes persistentes. No incluye grabaciones orquestales ni garantía de FPS.

## 4.6 — candidata a publicación

Juego web de simulación cozy desarrollado con JavaScript modular, Canvas 2D, CSS, Vite y Web Audio. Persistencia local con tres ranuras y recuperación de copias. Pruebas unitarias con Node Test Runner. Diseño adaptable a pantallas pequeñas. Estado: prototipo jugable en evolución; compilación y validación final pendientes. Evitar presentar las funcionalidades avanzadas no implementadas como completas.
